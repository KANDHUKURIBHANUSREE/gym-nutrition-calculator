# Gym Nutrition & Calorie Calculator

A Java-based console application that calculates a user's daily calorie requirements and estimated macronutrient intake based on personal details, activity level, and fitness goal.

## Features

- Accepts user details such as name, age, gender, weight, and height
- Calculates Basal Metabolic Rate (BMR)
- Calculates daily calorie requirements based on activity level
- Supports different fitness goals:
  - Weight Loss
  - Maintenance
  - Muscle Gain
- Calculates estimated macronutrient requirements:
  - Protein
  - Carbohydrates
  - Fats
- Uses object-oriented programming concepts
- Provides a simple command-line interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Scanner
- Switch Statements
- Basic Mathematical Calculations
